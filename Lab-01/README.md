# 🟢 ML Lab 01 – Introduction to Python for Data Analysis

This directory contains the foundational lab exercises for Data Analysis using Python, specifically tailored to familiarize users with core numerical and data manipulation libraries.

## 📝 Objective
Gain hands-on experience with `NumPy` and `Pandas` libraries, covering array manipulations, matrices creations, and tabular data operations such as reading, viewing, and exploring statistical characteristics from CSV files.

## 📂 Structure
- `notebook.ipynb` - Step-by-step implementation covering 8 specific experiments demonstrating basic analytics functionalities.
- `ML LAB -1.docx` - Lab report containing source code and execution outputs.

## 🧪 Experiments Covered
1. **NumPy Array Creation**: Constructing 1D arrays and identifying data types and shapes.
2. **Matrix Generation**: Using `np.zeros()` and `np.ones()` for initialized 2D arrays.
3. **Array Reshaping**: Generating continuous numerical ranges and reshaping dimensions using `reshape()`.
4. **Statistical Operations**: Finding min, max, mean, and sums on randomized arrays.
5. **Pandas DataFrames**: Transforming standard dictionaries into tabular structures.
6. **Data Injection**: Utilizing `read_csv()` to import datasets and inspecting limits via `head()` / `tail()`.
7. **Structural Identification**: Utilizing `info()` to detect dataset bounds and null value presence.
8. **Summary Statistics**: Running `describe()` to yield automated quantile and deviation metrics over datasets.
